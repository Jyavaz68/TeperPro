## v1.0.0
- First release of TeperPro: a clean, light-first, tabbed subscription page (Account / Set up / Advanced) for Pasarguard
- Usage ring with used/remaining, expiry date, account details and a 24h / 7d / 14d usage chart
- Set up tab: recommended app for the visitor's device, full app list with "Add subscription", copy link and QR
- Advanced tab: searchable configs with QR/copy, FAQ and a "Contact support" button (popup when no support ID is set)
- Installer with numbered menus for the accent color and the dark/light backgrounds (presets or #hex); `teperpro` command for update/brand/uninstall
- Lightweight: no blur or heavy effects; automatic lite mode on weak devices
